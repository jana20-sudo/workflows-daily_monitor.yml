Install as an Android Phone App

  1. Add this index.html file to your GitHub repository root (next to monitor_jobs.py and seen_jobs.json).
  2. In GitHub, open Settings > Pages, set Source to Deploy from a branch, pick main / /(root), and tap Save.
  3. Open your live https://<username>.github.io/<repo>/ link in Chrome on Android, tap the three dots (⋮), and choose Add to Home screen.

Tip: GitHub Pages works on public repos on the free plan. Keep your Gmail credentials safely inside GitHub Secrets—never inside any file.
